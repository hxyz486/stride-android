让轨迹动起来

1. 绘制路线打开后默认在线地图，允许定位即可查看当前位置。左上角切换在线或离线、定位及拖动／手绘／选点，双指可移动和缩放。长按地图可使用撤销和清空等辅助工具。

2. 调整配速滑动调节 0–5 分钟/公里，默认 3 分钟/公里（3′00″/km）。数值越小越快，0 特别表示原地停留；回放时也可调整。

3. 配置系统模拟定位打开手机设置 → 关于手机，连续点击版本号启用开发者选项。在开发者选项 → 选择模拟位置信息应用中，选择“行迹 STRIDE”。同时开启手机位置信息，并授予精确位置权限。

4. 开始回放按所画路线更新模拟位置。可暂停、继续或结束，结束会撤销本应用的模拟定位提供者。

关于传感器读取陀螺仪与修改陀螺仪是两回事。普通 Android 应用只能读取真实传感器；本应用生成的步态角速度供内部预览和导出，不会修改其他应用读到的陀螺仪。系统定位带有官方模拟标记，其他应用可能忽略该位置。

后台运行允许通知可在通知栏暂停或结束。部分手机需要在电池设置中允许本应用后台运行。被系统强制结束后不会自动恢复回放。
